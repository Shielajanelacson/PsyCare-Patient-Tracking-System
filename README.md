# PsyCare-Patient Tracking
PsyCare is a patient management system for psychology practitioners. It helps a doctor keep track of patients, their disorders and progress, appointment schedules with room assignments, clinical notes, and a full activity history. It runs locally on XAMPP.

This project was built as an individual school project using PHP, MySQL, HTML, JavaScript and Bootstrap.

REMINDER: All patients, names and notes in database.sql are fictional/not real patients. Do not store real patient information in this project.

1.Open XAMPP and start Apache and MySQL.

2.Place this project folder in C:\xampp\htdocs and name it psycare.

3.Go to http://localhost/phpmyadmin, click Import, choose database.sql, then press Import at the bottom of the page.

4.Visit http://localhost/psycare/, click Create one to make your account, and log in.
